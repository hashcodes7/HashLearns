# Eventual Consistency

Eventual consistency is a consistency model used in distributed computing to achieve high availability that informally guarantees that, if no new updates are made to a given data item, eventually all accesses to that item will return the last updated value.

![Eventual Consistency](https://upload.wikimedia.org/wikipedia/commons/thumb/8/87/Eventual_consistency.svg/500px-Eventual_consistency.svg.png)

It is highly used in systems like Amazon's Dynamo, Cassandra, and DNS.
