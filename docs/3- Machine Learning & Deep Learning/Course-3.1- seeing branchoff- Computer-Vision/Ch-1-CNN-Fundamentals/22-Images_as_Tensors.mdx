# 22. Images as Tensors

Images can be represented as tensors.
A single channel is RGB Value of a pixel. If a image is 1920x1080 it means it is essentially a cuboid of size 1920 x 1080 x 3

For a color image:

```text
channels × height × width
```

A batch adds another dimension, it is how many images will be analysed in 1 pass:

```text
batch × channels × height × width
```

pytorchcommonly uses:

```text
[B, C, H, W]
```

For example:

```text
[32, 3, 224, 224]
```

means:

```text
32 images
3 channels
224 height
224 width
```
