# 25. CNN Training

CNN training follows the same fundamental loop:

```text
batch
 ↓
forward
 ↓
loss
 ↓
backward
 ↓
optimizer step
```

The difference is the model architecture and the input data.

A CNN can therefore be trained with the same [PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) training principles already learned.
