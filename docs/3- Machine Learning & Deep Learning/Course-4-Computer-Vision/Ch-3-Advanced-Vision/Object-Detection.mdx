# 📦 Object Detection (YOLO)

Classification tells you "There is a Dog in this image."
Object Detection tells you "There is a Dog, and it is located inside this exact Box [X, Y, Width, Height]."

## 🚀 You Only Look Once (YOLO)
Older algorithms used to scan the image 2,000 times to find boxes. It was agonizingly slow.
YOLO split the image into a grid and predicted all the boxes in a single, massive forward pass! It was so fast it could process real-time webcam video at 60 FPS!
