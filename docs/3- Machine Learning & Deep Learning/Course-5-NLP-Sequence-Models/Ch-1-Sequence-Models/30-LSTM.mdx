# 30. LSTM

Long Short-Term Memory networks introduce gates to control information flow.

The main components are:

- forget gate
- input gate
- output gate
- cell state
- hidden state

[PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) provides:

```python
nn.LSTM
```

LSTMs were designed to handle longer dependencies more effectively than basic RNNs.
