# 31. GRU

Gated Recurrent Units are another gated recurrent architecture.

GRUs use fewer gates than LSTMs and do not maintain a separate cell state.

[PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) provides:

```python
nn.GRU
```

Both GRUs and LSTMs address limitations of basic RNNs.
