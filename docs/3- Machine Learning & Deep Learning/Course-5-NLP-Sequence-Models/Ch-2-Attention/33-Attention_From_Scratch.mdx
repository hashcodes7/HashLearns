# 33. Attention From Scratch

Given queries, keys, and values:

$$
Attention(Q,K,V)
=
softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

The process is:

```text
Q and K
 ↓
dot products
 ↓
scale
 ↓
softmax
 ↓
attention weights
 ↓
weighted V
 ↓
output
```

The attention matrix describes how strongly positions attend to one another.
