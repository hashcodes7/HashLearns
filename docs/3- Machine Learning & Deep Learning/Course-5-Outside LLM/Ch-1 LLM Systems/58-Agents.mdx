# 58. Agents

An agent combines a model with tools and a control loop.

A simplified agent loop:

```text
Observe
 ↓
Reason
 ↓
Choose action
 ↓
Use tool
 ↓
Observe result
 ↓
Repeat
```

An agent therefore differs from a single LLM call because it can perform multiple actions before producing the final result.
