# 36. Transformer Architecture

A Transformer block combines attention and a feed-forward network.

```text
Input
 ↓
LayerNorm
 ↓
Self-Attention
 ↓
Residual
 ↓
LayerNorm
 ↓
Feed Forward
 ↓
Residual
 ↓
Output
```

The major components are:

- self-attention
- feed-forward network
- residual connections
- layer normalization
