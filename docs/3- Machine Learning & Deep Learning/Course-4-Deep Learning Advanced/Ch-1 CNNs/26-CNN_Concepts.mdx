# 26. CNN Concepts

Important CNN ideas:

### Parameter Sharing

The same filter is applied at different spatial locations.

### Receptive Field

A neuron's receptive field is the region of the original image that can influence it.

### Feature Hierarchy

Early layers can learn simple patterns.

Later layers can combine them into more complex patterns.

```text
edges
 ↓
textures
 ↓
parts
 ↓
objects
```
