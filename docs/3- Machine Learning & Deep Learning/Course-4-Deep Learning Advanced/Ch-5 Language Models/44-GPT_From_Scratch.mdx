# 44. GPT From Scratch

A small GPT can be constructed from:

- tokenizer
- token embeddings
- positional information
- causal self-attention
- multi-head attention
- feed-forward networks
- residual connections
- layer normalization
- output projection

The complete flow is:

```text
Text
 ↓
Tokenizer
 ↓
Token IDs
 ↓
Embeddings
 ↓
Transformer Blocks
 ↓
Logits
```

This is the bridge from neural-network fundamentals to LLM architecture.
