# 34. Self-Attention

In self-attention, queries, keys, and values are produced from the same input sequence.

```text
Input sequence
      ↓
 Q    K    V
  \   |   /
   Attention
       ↓
    Output
```

For language modeling, causal masking prevents a token from attending to future tokens.

This preserves the autoregressive property:

$$
P(x_t|x_1,...,x_{t-1})
$$
