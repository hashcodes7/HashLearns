# 29. RNN Training

RNNs are trained using backpropagation through time.

The recurrent computation is conceptually unrolled:

```text
x1 → h1 → h2 → h3 → h4
      ↑    ↑    ↑    ↑
     x1   x2   x3   x4
```

Long sequences can cause:

- vanishing gradients
- exploding gradients

These limitations motivated gated recurrent architectures and eventually attention-based models.
