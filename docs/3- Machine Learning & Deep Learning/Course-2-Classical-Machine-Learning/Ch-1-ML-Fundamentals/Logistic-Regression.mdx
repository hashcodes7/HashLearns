# ⚖️ Logistic Regression

Despite the name, this is NOT a regression algorithm. It's for **Classification**!

## 🐶 Cat vs. Dog
Logistic Regression predicts probabilities (Is this a Cat or a Dog? Spam or Not Spam?).
It squishes a straight line into an **S-shape** (the Sigmoid curve), guaranteeing the output is a clean percentage between 0% and 100%.
