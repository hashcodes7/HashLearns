# ⚖️ Logistic Regression

Despite the name, this is NOT a regression algorithm. It's for **Classification**!

## 🍦 Temperature vs. Ice Cream High Sales
Logistic Regression predicts probabilities (e.g. Will today have High Ice Cream Sales based on Temperature?).
It squishes a straight line into an **S-shape** (the Sigmoid curve), guaranteeing the output is a clean percentage between 0% and 100%.

from scipy.special import expit # Sigmoid function
import matplotlib.pyplot as plt

# 1. Reproducible seed & realistic daily temperature samples (10°C to 40°C)

temp_train = np.sort(np.random.uniform(10, 40, 25))

# 2. Logistic model parameters: Logit z = w * temp + b

true_probs = expit(w * temp_train + b)

sales_train = np.random.binomial(1, true_probs)

temp_today = 28
z = w * temp_today + b
prob_today = expit(z)

print("Sampled Days:", len(temp_train))
print("Today's Temperature: %d°C" % temp_today)
print("Logit value (z): %.2f" % z)
print("High Sales Probability: %.1f%%" % (prob_today * 100))

if prob_today >= 0.5:
    print("Final Decision: HIGH SALES 🍦")
else:
    print("Final Decision: LOW SALES ❄️")

# --- Plotting Section (Intercepted for Chart.js) ---

# 1. Observed sales data points (25 Bernoulli sample days)
plt.scatter(temp_train, sales_train, label="Daily Sales Observations (25 days)")

# 2. Smooth S-curve (Fitted Logistic Sigmoid curve)
temp_curve = np.linspace(8, 42, 100)
prob_curve = expit(w * temp_curve + b)
plt.plot(temp_curve, prob_curve, label="Fitted Logistic Curve")

# 3. Prediction point for today (28°C)
plt.scatter([temp_today], [prob_today], label="Today's Prediction (28°C)")

# Label axis directions & title
plt.xlabel("Temperature (°C)")
plt.ylabel("High Sales Probability P(Y=1)")
plt.title("Logistic Regression: Ice Cream Sales vs Temperature")
