# 48. Loading Pretrained Weights

A pretrained model consists of learned parameter tensors.

[PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) commonly stores these in a `state_dict`.

```python
state = model.state_dict()
```

Loading compatible weights:

```python
model.load_state_dict(state)
```

The architecture must match the expected parameter shapes and names.

The important principle is:

```text
architecture
     ↓
matching parameter structure
     ↓
pretrained weights
```
