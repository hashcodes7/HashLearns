# 4. Vectorization and Matrix Multiplication

For multiple inputs:

$$
y=\sum_i w_i x_i+b
$$

This can be written as:

$$
\boxed{y=w^Tx+b}
$$

With multiple neurons:

$$
\boxed{y=Wx+b}
$$

Example:

```python
import numpy as np

x = np.array([2, 3, 4])

W = np.array([
    [1, 2, 3],
    [2, 1, 1]
])

b = np.array([5, 2])

y = W @ x + b
```

Each row of $W$ represents one neuron.
