# 7. Hidden Layers

A neural network can contain hidden layers.

For one hidden layer:

$$
z^{(1)}=W^{(1)}x+b^{(1)}
$$

$$
a^{(1)}=ReLU(z^{(1)})
$$

$$
y=W^{(2)}a^{(1)}+b^{(2)}
$$

The hidden layer transforms the input into an intermediate representation.

```text
Input
 ↓
Hidden Layer
 ↓
Activation
 ↓
Output Layer
 ↓
Prediction
```
