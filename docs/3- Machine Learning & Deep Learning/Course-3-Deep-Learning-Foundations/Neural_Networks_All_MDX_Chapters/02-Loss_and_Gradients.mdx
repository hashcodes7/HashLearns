# 2. Loss and Gradients

For a target value $t$ and prediction $y$:

$$
error = t-y
$$

Using squared loss:

$$
L=(t-y)^2
$$

The gradients are:

$$
\boxed{\frac{\partial L}{\partial w}=-2x(t-y)}
$$

$$
\boxed{\frac{\partial L}{\partial b}=-2(t-y)}
$$

Gradient descent updates the parameters:

$$
w=w-\eta\frac{\partial L}{\partial w}
$$

$$
b=b-\eta\frac{\partial L}{\partial b}
$$

where $\eta$ is the learning rate.
