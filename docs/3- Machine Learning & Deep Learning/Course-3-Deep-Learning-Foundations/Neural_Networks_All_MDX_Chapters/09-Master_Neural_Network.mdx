# 9. Master Neural Network

We use one network throughout the training progression.

```text
x1 ─────┬────→ Neuron 1 ─→ ReLU ─→ a1 ──┐
        │                                 │
x2 ─────┼────→ Neuron 2 ─→ ReLU ─→ a2 ──┼→ Output → y
        │                                 │
        └────→ Neuron 3 ─→ ReLU ─→ a3 ──┘
```

There are:
- 2 inputs
- 3 hidden neurons
- ReLU
- 1 output neuron

Mathematically:

$$
z=Wx+b_{hidden}
$$

$$
a=ReLU(z)
$$

$$
y=w_{output}^Ta+b_{output}
$$

The network contains 13 trainable parameters.

Example initialization:

```python
x1 = 2
x2 = 3
target = 20

W = [
    [1, 2],
    [2, 1],
    [1, 1]
]

b_hidden = [1, 2, 1]

w_output = [1, 2, 1]
b_output = 1
```

Forward pass:

```text
z = [9, 9, 6]
a = [9, 9, 6]
y = 34
loss = (20 - 34)^2 = 196
```
