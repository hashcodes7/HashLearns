# 1. Single Neuron

A single neuron can be represented as:

$$
y = wx+b
$$

where:
- $x$ = input
- $w$ = weight
- $b$ = bias
- $y$ = prediction

## Example

```python
x = 3
w = 2
b = 1

y = w * x + b

print(y)
```

Output:

```text
7
```

The neuron takes an input, multiplies it by a weight, adds a bias, and produces a prediction.
