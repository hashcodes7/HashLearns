# Phase 10 — Real Dataset

Until now, we used manually created numbers.

Now we use a real dataset.

A dataset contains many examples:

$$
X=
\begin{bmatrix}
x_{11}&x_{12}&\cdots&x_{1n}\\
x_{21}&x_{22}&\cdots&x_{2n}\\
\vdots&\vdots&&\vdots\\
x_{m1}&x_{m2}&\cdots&x_{mn}
\end{bmatrix}
$$

Each row represents one example.

---

## 10.1 Simple Dataset

We can start with a small dataset:

```python
import numpy as np

X = np.array([
    [1, 2],
    [2, 3],
    [3, 4],
    [4, 5]
])

y = np.array([
    5,
    8,
    11,
    14
])

print(X)
print(y)
```

The relationship is:

$$
y=2x_1+x_2
$$

For example:

$$
2(1)+2=4
$$

If the target is 5, the model still needs to learn the relationship from the examples rather than being given the formula.

---

## 10.2 Training Data

We normally split data into:

```text
Training data → learn parameters
Test data     → evaluate the model
```

The model should not simply memorize the training examples.

---

## 10.3 Python Dataset Loop

```python
for inputs, target in zip(X, y):
    print("inputs:", inputs)
    print("target:", target)
```

Output:

```text
inputs: [1 2]
target: 5

inputs: [2 3]
target: 8

inputs: [3 4]
target: 11

inputs: [4 5]
target: 14
```

---

## Key Idea

A real dataset gives the network many examples from which it can learn the underlying relationship.
