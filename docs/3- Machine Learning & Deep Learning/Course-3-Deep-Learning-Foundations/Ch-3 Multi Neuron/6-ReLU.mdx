# Phase 6 — Activation Functions

## 6.1 ReLU

ReLU stands for **Rectified Linear Unit**.

It is defined as:

$$
\boxed{ReLU(x)=\max(0,x)}
$$

So:

- If \(x>0\), output is \(x\)
- If \(x\leq0\), output is \(0\)

Examples:

$$
ReLU(5)=5
$$

$$
ReLU(-3)=0
$$

---

## 6.2 Why ReLU?

Without an activation function, stacking layers still produces one overall linear function.

ReLU introduces non-linearity.

A neuron can therefore calculate:

$$
z=Wx+b
$$

then:

$$
\boxed{y=ReLU(z)}
$$

---

## 6.3 Python

```python
def relu(x):
    return max(0, x)

print(relu(5))
print(relu(-3))
```

Output:

```text
5
0
```

For multiple values:

```python
import numpy as np

x = np.array([-3, -1, 0, 2, 5])

y = np.maximum(0, x)

print(y)
```

Output:

```text
[0 0 0 2 5]
```

---

## Key Idea

The layer first calculates:

$$
z=Wx+b
$$

Then ReLU:

$$
\boxed{y=\max(0,z)}
$$
