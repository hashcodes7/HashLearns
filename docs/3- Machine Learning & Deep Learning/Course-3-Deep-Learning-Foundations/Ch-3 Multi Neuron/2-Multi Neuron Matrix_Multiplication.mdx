## 4.5 Matrix Multiplication

Suppose we have 2 neurons, each with 3 weights.

The weights can be stored in a matrix:

$$
W=
\begin{bmatrix}
w_{11}&w_{12}&w_{13}\\
w_{21}&w_{22}&w_{23}
\end{bmatrix}
$$

The input is:

$$
x=
\begin{bmatrix}
x_1\\
x_2\\
x_3
\end{bmatrix}
$$

Then:

$$
Wx=
\begin{bmatrix}
w_{11}x_1+w_{12}x_2+w_{13}x_3\\
w_{21}x_1+w_{22}x_2+w_{23}x_3
\end{bmatrix}
$$

Each row of \(W\) represents one neuron's weights.

So matrix multiplication calculates the output of multiple neurons at once.

---

## 4.6 Adding Bias

Each neuron has its own bias:

$$
b=
\begin{bmatrix}
b_1\\
b_2
\end{bmatrix}
$$

Therefore:

$$
\boxed{y=Wx+b}
$$

For the example above:

$$
y=
\begin{bmatrix}
w_{11}x_1+w_{12}x_2+w_{13}x_3+b_1\\
w_{21}x_1+w_{22}x_2+w_{23}x_3+b_2
\end{bmatrix}
$$

---

## Key Idea

One neuron:

$$
\boxed{y=w^Tx+b}
$$

Multiple neurons:

$$
\boxed{y=Wx+b}
$$

The matrix \(W\) contains the weights of all neurons.
