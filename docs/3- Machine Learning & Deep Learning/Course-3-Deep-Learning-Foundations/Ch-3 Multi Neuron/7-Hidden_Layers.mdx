# Phase 7 — Hidden Layers

A neural network becomes more powerful when we place layers between the input and output.

These intermediate layers are called **hidden layers**.

---

## 7.1 Basic Structure

A simple network can look like:

```text
Input → Hidden Layer → Output
```

For example:

```text
x1 ──┐
x2 ──┼──→ [Neuron] ──┐
x3 ──┘               ├──→ Output
                     │
          [Neuron] ──┘
```

---

## 7.2 Hidden Layer Calculation

First calculate:

$$
z^{(1)}=W^{(1)}x+b^{(1)}
$$

Then apply an activation function:

$$
\boxed{a^{(1)}=ReLU(z^{(1)})}
$$

The hidden layer output becomes the input to the next layer.

---

## 7.3 Two-Layer Network

The second layer calculates:

$$
z^{(2)}=W^{(2)}a^{(1)}+b^{(2)}
$$

Therefore:

$$
\boxed{y=W^{(2)}a^{(1)}+b^{(2)}}
$$

The complete flow is:

$$
x
\rightarrow
W^{(1)}x+b^{(1)}
\rightarrow
ReLU
\rightarrow
W^{(2)}a^{(1)}+b^{(2)}
\rightarrow y
$$

---

## 7.4 Python

```python
import numpy as np

x = np.array([2, 3])

W1 = np.array([
    [1, 2],
    [2, 1]
])

b1 = np.array([1, 1])

W2 = np.array([
    [1, 2]
])

b2 = np.array([1])

z1 = W1 @ x + b1
a1 = np.maximum(0, z1)

y = W2 @ a1 + b2

print(y)
```

---

## Key Idea

A hidden layer transforms the input into a new representation.

$$
\boxed{a^{(1)}=ReLU(W^{(1)}x+b^{(1)})}
$$
