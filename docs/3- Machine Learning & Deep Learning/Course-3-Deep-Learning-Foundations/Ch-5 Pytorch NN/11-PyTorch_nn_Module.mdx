# 11. Building a Neural Network with `nn.Module`

We can represent the same network using PyTorch's standard model abstraction.

```python
import torch
import torch.nn as nn

class NeuralNetwork(nn.Module):

    def __init__(self):
        super().__init__()

        self.hidden = nn.Linear(2, 3)
        self.output = nn.Linear(3, 1)

    def forward(self, x):
        x = self.hidden(x)
        x = torch.relu(x)
        x = self.output(x)

        return x
```

Create the model:

```python
model = NeuralNetwork()
```

Create the optimizer:

```python
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.001
)
```

Training:

```python
x = torch.tensor([2.0, 3.0])
target = torch.tensor(20.0)

for step in range(1000):
    optimizer.zero_grad()

    prediction = model(x)

    loss = (target - prediction.squeeze()) ** 2

    loss.backward()

    optimizer.step()
```

The key abstraction is:

```text
nn.Module
   ↓
nn.Linear
   ↓
model.parameters()
   ↓
optimizer
```

The mathematics is unchanged; PyTorch now manages the network structure and parameters.
