# 9. Building a Neural Network with `nn.Module`

In the previous chapter, we trained our neural network using PyTorch tensors, autograd, and an optimizer.

The network worked, but we manually created and managed every parameter:

```python
W
b_hidden
w_output
b_output
```

PyTorch provides a cleaner and standard way to define neural networks using:

- `nn.Module`
- `nn.Linear`
- activation functions
- `model.parameters()`

---

## 1. Our Network

Our network has:

```text
2 inputs
   ↓
3 hidden neurons
   ↓
ReLU
   ↓
1 output neuron
```

Mathematically:

$$
z = W_1x + b_1
$$

$$
a = ReLU(z)
$$

$$
y = W_2a + b_2
$$

---

## 2. `nn.Module`

`nn.Module` is the base class for neural networks in PyTorch.

```python
import torch
import torch.nn as nn

class NeuralNetwork(nn.Module):

    def __init__(self):
        super().__init__()

    def forward(self, x):
        pass
```

There are two important methods.

### `__init__()`

Defines the components and parameters of the network.

### `forward()`

Defines how data moves through the network.

```text
__init__()
    ↓
Define network

forward(x)
    ↓
Run network
```

---

## 3. `nn.Linear`

Previously we manually created the weight matrix and bias.

A linear layer already contains both:

```python
nn.Linear(in_features, out_features)
```

For our hidden layer:

```python
nn.Linear(2, 3)
```

This means:

```text
2 inputs
↓
3 neurons
```

It implements:

$$
z = Wx+b
$$

For the output layer:

```python
nn.Linear(3, 1)
```

This means:

```text
3 hidden outputs
↓
1 output
```

---

## 4. Define the Model

```python
class NeuralNetwork(nn.Module):

    def __init__(self):
        super().__init__()

        self.hidden = nn.Linear(2, 3)
        self.output = nn.Linear(3, 1)

    def forward(self, x):
        x = self.hidden(x)
        x = torch.relu(x)
        x = self.output(x)

        return x
```

The forward pass is:

```text
x
 ↓
Linear(2 → 3)
 ↓
ReLU
 ↓
Linear(3 → 1)
 ↓
y
```

## 5. Parameter Count


So:

```text

```

The output layer contains:

```text

```

So:

```text

```

Total:

$$
9+4=13

trainable parameters.

## 6. Creating the Model

```python
model = NeuralNetwork()
```

PyTorch now knows about all trainable parameters inside the model.

We can access them with:

```python
model.parameters()
```

For example:

```python
for parameter in model.parameters():
    print(parameter)
```

We no longer need to manually maintain:

```python
W
b_hidden
w_output
b_output
```

## 7. Forward Pass

Our input is:

```python
x = torch.tensor([2.0, 3.0])
```

We pass it through the model:

```python
prediction = model(x)
```

PyTorch calls the model's `forward()` method.

The calculation is:

$$

$$

$$

$$

$$
y=W_2a+b_2
$$

## 8. Loss

Our target is:

```python
target = torch.tensor(20.0)
```

Our squared-error loss is:

$$
L=(target-y)^2
$$

In PyTorch:

```python
loss = (target - prediction.squeeze()) ** 2
```

---

## 9. Backpropagation

We calculate all gradients using:

```python
loss.backward()
```

PyTorch automatically computes gradients for all trainable parameters.

Conceptually:

$$
rac{\partial L}{\partial W_1}
$$

$$
rac{\partial L}{\partial b_1}
$$

$$
rac{\partial L}{\partial W_2}
$$

$$
rac{\partial L}{\partial b_2}
$$

## 10. Optimizer

Previously we gave every parameter to the optimizer manually.

Now:

```python
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.001
)
```

`model.parameters()` automatically provides all trainable parameters.

## 11. Complete Training

```python
import torch
import torch.nn as nn

class NeuralNetwork(nn.Module):

    def __init__(self):
        super().__init__()

        self.hidden = nn.Linear(2, 3)
        self.output = nn.Linear(3, 1)

    def forward(self, x):
        x = self.hidden(x)
        x = torch.relu(x)
        x = self.output(x)

        return x


x = torch.tensor([2.0, 3.0])
target = torch.tensor(20.0)

model = NeuralNetwork()

optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.001
)

for step in range(1000):

    optimizer.zero_grad()

    prediction = model(x)

    loss = (target - prediction.squeeze()) ** 2

    loss.backward()

    optimizer.step()
```

The standard training sequence is:

$$
oxed{
zero\_grad

ightarrow
forward

ightarrow
loss

ightarrow
backward

ightarrow
step
}
$$

## 13. Why `nn.Module` Matters

`nn.Module` gives PyTorch a standard structure for neural networks.

It allows PyTorch to track:

- trainable parameters
- layers
- gradients
- model state
- nested modules

The same structure works for small and very large networks.

For example:

```python
class NeuralNetwork(nn.Module):

    def __init__(self):
        super().__init__()

        self.layer1 = nn.Linear(10, 128)
        self.layer2 = nn.Linear(128, 64)
        self.layer3 = nn.Linear(64, 10)

    def forward(self, x):
        x = torch.relu(self.layer1(x))
        x = torch.relu(self.layer2(x))
        x = self.layer3(x)

        return x
```

The mathematics remains the same.

---

## 14. Three Levels of Abstraction

We have progressed through three levels.

### Level 1 — Mathematics

We manually worked with:

$$
y=Wx+b
$$

and calculated gradients.

### Level 2 — PyTorch tensors

PyTorch calculated gradients with:

```python
loss.backward()
```

but we still manually managed parameters.

### Level 3 — PyTorch models

PyTorch now manages the network structure through:

```python
nn.Module
nn.Linear
model.parameters()
```

The underlying mathematics has not changed.

We have simply moved more of the implementation into PyTorch.

```text
Mathematics
     ↓
PyTorch tensors
     ↓
PyTorch neural-network modules
```

## 15. Key Takeaways

| Concept | Meaning |
|---|---|
| `nn.Module` | Base class for PyTorch neural networks |
| `__init__()` | Defines layers and components |
| `forward()` | Defines data flow |
| `nn.Linear` | Implements a linear layer `Wx+b` |
| `model.parameters()` | Returns trainable parameters |
| `loss.backward()` | Computes gradients |
| `optimizer.step()` | Updates parameters |
| `optimizer.zero_grad()` | Clears previous gradients |
