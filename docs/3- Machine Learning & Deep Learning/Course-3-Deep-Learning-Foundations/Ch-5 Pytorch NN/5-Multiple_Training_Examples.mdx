# 4. Multiple Training Examples

A neural network should learn from multiple examples rather than a single input.

Suppose:

```python
x = [
    [1, 2],
    [2, 3],
    [3, 4],
    [4, 5]
]
```

and targets:

```python
target = [
    10,
    15,
    20,
    25
]
```

The important new dimension is the batch dimension.

```text
Number of examples × Number of features
```

So the input shape is:

```text
[4, 2]
```

A pytorchmodel can process all four examples at once:

```python
x = torch.tensor([
    [1.0, 2.0],
    [2.0, 3.0],
    [3.0, 4.0],
    [4.0, 5.0]
])

prediction = model(x)
```

The model performs the same computation for every example.

This is vectorized batch training.
