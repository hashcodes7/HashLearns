The training process is:

```text
Forward pass
     ↓
Calculate loss
     ↓
loss.backward()
     ↓
Autograd calculates gradients
     ↓
Update parameters
     ↓
Clear gradients
     ↓
Repeat
```

## 9. Standard Pytorch Optimizer

The manual update above is useful for understanding the mechanics.

In normal Pytorch training, an optimizer handles parameter updates.

```python
optimizer = torch.optim.SGD(
    [W, b_hidden, w_output, b_output],
    lr=0.001
)
```

Training then becomes:

```python
for step in range(1000):

    optimizer.zero_grad()

    # Forward pass
    z = W @ x + b_hidden
    a = torch.relu(z)
    y = w_output @ a + b_output

    # Loss
    loss = (target - y) ** 2

    # Backpropagation
    loss.backward()

    # Parameter update
    optimizer.step()
```

The standard Pytorch pattern is:

$$
\boxed{
zero\_grad
\rightarrow
forward
\rightarrow
loss
\rightarrow
backward
\rightarrow
step
}
$$

## 10. Manual Neural Network vs Pytorch

### Manual

```text
Forward
   ↓
Loss
   ↓
Derive gradients
   ↓
Calculate gradients
   ↓
Update parameters
```

### Pytorch

```text
Forward
   ↓
Loss
   ↓
loss.backward()
   ↓
Autograd calculates gradients
   ↓
optimizer.step()
```

The mathematics has not changed.

$$
\boxed{
\text{pytorchAutograd}
=
\text{automatic chain-rule differentiation}
}
$$
