# 2. PyTorch Training

## 1. From Manual Neural Networks to [PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx)

We previously trained the same network manually:

$$
x \rightarrow Wx+b_h \rightarrow ReLU \rightarrow w^Ta+b_o \rightarrow y
$$

with:

$$
L=(target-y)^2
$$

[PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) keeps the same mathematics but automates gradient calculation.

$$
\boxed{
Forward\ Pass
\rightarrow
Loss
\rightarrow
loss.backward()
\rightarrow
Parameter\ Update
\rightarrow
Repeat
}
$$

---

## 2. The Network

Our network has:

- 2 inputs
- 3 hidden neurons
- ReLU
- 1 output neuron
- 13 trainable parameters

Hidden layer:

$$
z=Wx+b_h
$$

$$
a=ReLU(z)
$$

Output layer:

$$
y=w^Ta+b_o
$$

Loss:

$$
L=(target-y)^2
$$

---

## 3. Tensors and Gradient Tracking

```python
import torch

x = torch.tensor([2.0, 3.0])
target = torch.tensor(20.0)

W = torch.tensor([
    [1.0, 2.0],
    [2.0, 1.0],
    [1.0, 1.0]
], requires_grad=True)

b_hidden = torch.tensor(
    [1.0, 2.0, 1.0],
    requires_grad=True
)

w_output = torch.tensor(
    [1.0, 2.0, 1.0],
    requires_grad=True
)

b_output = torch.tensor(
    1.0,
    requires_grad=True
)
```

`requires_grad=True` tells [PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) to track operations involving these parameters so their gradients can be calculated.

---

## 4. Forward Pass

```python
z = W @ x + b_hidden

a = torch.relu(z)

y = w_output @ a + b_output

loss = (target - y) ** 2
```

Mathematically:

$$
z=Wx+b_h
$$

$$
a=ReLU(z)
$$

$$
y=w^Ta+b_o
$$

$$
L=(target-y)^2
$$

---

## 5. Backpropagation with Autograd

Previously we manually calculated all derivatives using the chain rule.

[PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) performs this automatically:

```python
loss.backward()
```

After this:

```python
W.grad
```

contains:

$$
\frac{dL}{dW}
$$

and similarly:

```python
b_hidden.grad
w_output.grad
b_output.grad
```

contain the corresponding gradients.

Therefore:

$$
\boxed{loss.backward() \Rightarrow \text{gradients}}
$$

---

## 6. Parameter Update

Gradient descent is still:

$$
\boxed{
\theta_{new}
=
\theta_{old}
-
\eta
\frac{dL}{d\theta}
}
$$

For a manual update:

```python
learning_rate = 0.001

with torch.no_grad():
    W -= learning_rate * W.grad
    b_hidden -= learning_rate * b_hidden.grad
    w_output -= learning_rate * w_output.grad
    b_output -= learning_rate * b_output.grad
```

`torch.no_grad()` prevents the update operation itself from being added to the computation graph.

---

## 7. Clearing Gradients

[PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) gradients accumulate.

When training repeatedly, gradients must be cleared before the next backward pass.

With manual updates:

```python
W.grad.zero_()
b_hidden.grad.zero_()
w_output.grad.zero_()
b_output.grad.zero_()
```

With an optimizer, this is normally handled by:

```python
optimizer.zero_grad()
```

---

## 8. Complete Training Loop

The complete network can now be trained repeatedly:

```python
import torch


x = torch.tensor([2.0, 3.0])
target = torch.tensor(20.0)


W = torch.tensor([
    [1.0, 2.0],
    [2.0, 1.0],
    [1.0, 1.0]
], requires_grad=True)

b_hidden = torch.tensor(
    [1.0, 2.0, 1.0],
    requires_grad=True
)

w_output = torch.tensor(
    [1.0, 2.0, 1.0],
    requires_grad=True
)

b_output = torch.tensor(
    1.0,
    requires_grad=True
)


learning_rate = 0.001


for step in range(1000):

    # Forward pass
    z = W @ x + b_hidden
    a = torch.relu(z)
    y = w_output @ a + b_output

    # Loss
    loss = (target - y) ** 2

    # Backpropagation
    loss.backward()

    # Parameter update
    with torch.no_grad():
        W -= learning_rate * W.grad
        b_hidden -= learning_rate * b_hidden.grad
        w_output -= learning_rate * w_output.grad
        b_output -= learning_rate * b_output.grad

    # Clear gradients
    W.grad.zero_()
    b_hidden.grad.zero_()
    w_output.grad.zero_()
    b_output.grad.zero_()
```

The training process is:

```text
Forward pass
     ↓
Calculate loss
     ↓
loss.backward()
     ↓
Autograd calculates gradients
     ↓
Update parameters
     ↓
Clear gradients
     ↓
Repeat
```

---

## 9. Standard [PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) Optimizer

The manual update above is useful for understanding the mechanics.

In normal [PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) training, an optimizer handles parameter updates.

```python
optimizer = torch.optim.SGD(
    [W, b_hidden, w_output, b_output],
    lr=0.001
)
```

Training then becomes:

```python
for step in range(1000):

    optimizer.zero_grad()

    # Forward pass
    z = W @ x + b_hidden
    a = torch.relu(z)
    y = w_output @ a + b_output

    # Loss
    loss = (target - y) ** 2

    # Backpropagation
    loss.backward()

    # Parameter update
    optimizer.step()
```

The standard [PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) pattern is:

$$
\boxed{
zero\_grad
\rightarrow
forward
\rightarrow
loss
\rightarrow
backward
\rightarrow
step
}
$$

## 10. Manual Neural Network vs [PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx)

### Manual

```text
Forward
   ↓
Loss
   ↓
Derive gradients
   ↓
Calculate gradients
   ↓
Update parameters
```

### [PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx)

```text
Forward
   ↓
Loss
   ↓
loss.backward()
   ↓
Autograd calculates gradients
   ↓
optimizer.step()
```

The mathematics has not changed.

$$
\boxed{
\text{[PyTorch](../../Course-1-Mathematics and Frameworks/Ch-9 Deep-Learning-Frameworks/PyTorch.mdx) Autograd}
=
\text{automatic chain-rule differentiation}
}
$$
