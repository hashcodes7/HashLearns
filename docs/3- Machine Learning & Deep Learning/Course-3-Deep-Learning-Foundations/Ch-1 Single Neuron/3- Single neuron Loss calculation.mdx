## Loss Calculation
For measuring the size of the mistake, we don't want the negative sign to cancel anything. Loss function is used to measure the error between predicted value and actual value, and it is always positive.
<PyScriptRunner
  title="Linear Regression Model Fit (House Size vs Price)"
  initialCode={`
x = 3.0
w = 2.0
b = 1.0

target = 10.0

prediction = w * x + b

error = target - prediction
loss = error ** 2

print("Prediction:", prediction)
print("Error:", error)
print("Loss:", loss)
`}
/>
