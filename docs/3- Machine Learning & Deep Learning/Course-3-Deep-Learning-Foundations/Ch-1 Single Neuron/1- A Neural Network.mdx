# 📈 Single Neuron Network

The "Hello World" of Machine Learning. 

## 📏 Drawing the Line
lets say y=mx+b is equation of 1 neuron. 
for any x if we need our neuron to behave correctly, we have 2 ways to do it, weights and bias. 
$$ y=wx+b $$
## Weights vs bias
### Weight
Changing w changes how strongly the output responds to changes in x.

### Bias

Changing b shifts the whole output up or down.
