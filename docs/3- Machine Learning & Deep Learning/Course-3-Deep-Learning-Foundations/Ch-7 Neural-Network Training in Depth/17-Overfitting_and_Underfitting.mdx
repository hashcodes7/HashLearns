# 17. Overfitting and Underfitting

## Underfitting

The model is too simple to learn the underlying pattern.

```text
training performance: poor
validation performance: poor
```

## Overfitting

The model learns the training examples too specifically.

```text
training performance: very good
validation performance: worse
```

The goal is good generalization:

$$
\boxed{\text{Good performance on unseen data}}
$$

Training and validation loss curves help identify these behaviors.
