# 15. Binary Classification

While regression predicts continuous values (like temperature or stock prices), **classification predicts categories or classes**.

In **Binary Classification**, we predict between exactly two outcomes. 
Real-world examples include:
- **Spam Detection**: Spam (1) vs. Not Spam (0)
- **Medical Diagnosis**: Malignant (1) vs. Benign (0)
- **Banking**: Fraudulent Transaction (1) vs. Legitimate (0)

For binary classification, our target labels are conventionally mathematically represented as:
```text
0 or 1
```

### The Model Output: Logits
A neural network's final linear layer produces raw, unnormalized scores called **logits**. Let's call the logit for a single prediction $z$. 
Because a logit can be any real number from $-\infty$ to $+\infty$, we can't treat it as a probability yet.

### The Sigmoid Function
To convert the raw logit $z$ into a probability (a number between 0 and 1), we pass it through the **Sigmoid** activation function:

$$
\sigma(z) = \frac{1}{1 + e^{-z}}
$$

A common decision rule to translate this probability into a final class is:
```text
probability >= 0.5 → Class 1
probability < 0.5  → Class 0
```

### Binary Cross-Entropy (BCE) Loss
To train our model, we need to penalize it when its predicted probability diverges from the true label. **Binary Cross-Entropy** (BCE) loss does exactly this. It heavily penalizes the model if it is *confidently wrong* (e.g., predicting 0.99 for a class that is actually 0).

In PyTorch, you could technically apply `nn.Sigmoid()` and then `nn.BCELoss()`. However, for **numerical stability**, it is standard practice to combine them into a single step:

```python
loss_function = torch.nn.BCEWithLogitsLoss()
```
This function takes the raw logits ($z$) and the target labels directly, applying the sigmoid mathematically under the hood in a way that avoids floating-point precision issues.

### Complete Runnable Example

Let's build a simple PyTorch binary classifier. We'll train a small network to classify some dummy 2D data points.

```python r
import torch
import torch.nn as nn
import torch.optim as optim
import matplotlib.pyplot as plt

# 1. Create dummy data (100 samples, 2 features each)
# Let's say class 1 tends to have higher values, class 0 has lower
X_class0 = torch.randn(50, 2) - 2.0
X_class1 = torch.randn(50, 2) + 2.0
X = torch.cat([X_class0, X_class1], dim=0)

# Labels: 50 zeros, then 50 ones. Need to be float for BCEWithLogitsLoss
y = torch.cat([torch.zeros(50, 1), torch.ones(50, 1)], dim=0)

# 2. Define the Binary Classifier
class BinaryClassifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer = nn.Linear(2, 1) # 2 inputs, 1 logit output
        
    def forward(self, x):
        return self.layer(x) # Return raw logit!

model = BinaryClassifier()
criterion = nn.BCEWithLogitsLoss()
optimizer = optim.SGD(model.parameters(), lr=0.1)

# 3. Training Loop
losses = []
for epoch in range(50):
    optimizer.zero_grad()
    
    # Forward pass
    logits = model(X)
    loss = criterion(logits, y)
    
    # Backward pass and optimize
    loss.backward()
    optimizer.step()
    
    losses.append(loss.item())

# Plot the training loss
plt.plot(losses, color='blue', label='BCE Loss')
plt.xlabel("Epoch")
plt.ylabel("Loss")
plt.title("Binary Classification Training Loss")
plt.legend()
plt.show()

# Let's test it on a new point!
test_point = torch.tensor([[2.5, 2.5]])
test_logit = model(test_point)
test_prob = torch.sigmoid(test_logit)

print(f"Raw Logit: {test_logit.item():.4f}")
print(f"Probability of Class 1: {test_prob.item():.4f}")
print(f"Prediction: {'Class 1' if test_prob.item() >= 0.5 else 'Class 0'}")
```
