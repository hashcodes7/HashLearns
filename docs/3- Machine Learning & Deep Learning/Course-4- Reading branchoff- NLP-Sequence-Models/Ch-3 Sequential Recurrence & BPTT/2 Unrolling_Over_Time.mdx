# Unrolling Over Time: The Comic Strip

In the last section, we built our Vanilla RNN "blender." It takes a word, mixes it with its memory, and repeats. 

This loop is great for *processing* data, but it causes a massive headache when we try to *train* the AI.

Remember from Course 3 that we train neural networks using Backpropagation—finding the mistake at the end and tracing it backwards to adjust the weights. But how do you trace a mistake backward when the network is stuck in a looping time cycle? 

To solve this, AI researchers use a mental trick called **Unrolling Over Time**.

---

## The Flipbook vs The Comic Strip

Imagine you draw a stick figure animation on the corner of a notebook. When you flip the pages rapidly, the stick figure runs across the page. 

- This flipbook is how an RNN actually runs. It's **one** piece of paper (one neural network) that just keeps updating itself over time. 

But if you want to find out exactly which page you drew the legs wrong, flipping it super fast doesn't help. 

Instead, you would **unroll** the flipbook. You rip out every single page and lay them side-by-side on a giant table. 
Now, instead of one moving picture, you have a **comic strip**. You can see Page 1, Page 2, and Page 3 all at the exact same time.

<div style={{backgroundColor: '#e6f7ff', padding: '10px', borderRadius: '5px'}}>
<strong>Unrolling:</strong> We pretend the RNN isn't a loop. If a sentence has 5 words, we pretend we have 5 separate neural networks standing next to each other, passing notes from left to right.
</div>

## The "Cloned" Networks

When we unroll an RNN, it looks like a standard, deep neural network! 

- **Step 1 Network** looks at Word 1 and passes its memory to Step 2.
- **Step 2 Network** looks at Word 2, takes the memory from Step 1, and passes its new memory to Step 3.

**But here is the absolute most important rule:**
Even though it *looks* like 5 different neural networks on paper, **they all share the exact same weights (brain).** It’s literally the exact same blender, just drawn 5 different times to make the math easier to visualize.

By laying time out flat on a table, we can finally do math on it!

## Python Code Example

Here is how unrolling over time works in code. Notice how an explicit `for` loop unfolds the sequence step-by-step (like pages in a comic strip), reusing the exact same shared weight matrices (`W_xh` and `W_hh`) at each time step:

```python r
import torch
import torch.nn as nn

# Set seed for reproducibility
torch.manual_seed(42)

# Sequence configuration: 5 time steps (words), batch size 1, input dim 3, hidden dim 4
seq_len = 5
batch_size = 1
input_dim = 3
hidden_dim = 4

# Sequence of 5 words (comic strip frames)
# Shape: (seq_len, batch_size, input_dim)
x_seq = torch.randn(seq_len, batch_size, input_dim)

# 1. Define shared weights (the single "brain" reused at every time step)
W_xh = nn.Parameter(torch.randn(hidden_dim, input_dim))
W_hh = nn.Parameter(torch.randn(hidden_dim, hidden_dim))
b_h = nn.Parameter(torch.zeros(hidden_dim))

# Initial hidden state (blank memory before reading the first word)
h_t = torch.zeros(batch_size, hidden_dim)

# 2. Unroll over time: loop through each step in the sequence
all_hidden_states = []

print("--- Unrolling the RNN Over Time ---")
for t in range(seq_len):
    x_t = x_seq[t]  # Current word vector: (batch_size, input_dim)
    
    # The exact same shared weights are used at every step t!
    h_t = torch.tanh(x_t @ W_xh.T + h_t @ W_hh.T + b_h)
    all_hidden_states.append(h_t)
    
    first_two = [round(v, 3) for v in h_t[0, :2].tolist()]
    print(f"Step {t + 1} (Frame {t + 1}): Memory shape = {tuple(h_t.shape)}, first 2 values = {first_two}")

# Stack collected hidden states into the full sequence: (seq_len, batch_size, hidden_dim)
unrolled_output = torch.stack(all_hidden_states, dim=0)
print(f"\nFinal unrolled sequence shape: {tuple(unrolled_output.shape)}")

# 3. Compare with PyTorch's nn.RNN (which performs this exact unrolling internally)
rnn = nn.RNN(input_size=input_dim, hidden_size=hidden_dim, bias=True)
with torch.no_grad():
    rnn.weight_ih_l0.copy_(W_xh)
    rnn.weight_hh_l0.copy_(W_hh)
    rnn.bias_ih_l0.copy_(b_h)
    rnn.bias_hh_l0.zero_()

h_0 = torch.zeros(1, batch_size, hidden_dim)
nn_rnn_output, _ = rnn(x_seq, h_0)

print(f"Matches PyTorch nn.RNN output: {torch.allclose(unrolled_output, nn_rnn_output, atol=1e-6)}")
```
