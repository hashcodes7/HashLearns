# GloVe & Matrix Factorization: The Giant Spreadsheet

So far, we've talked about **Word2Vec**, which acts like a student studying with flashcards. It reads sentences one by one, playing "fill in the blank" games, and slowly learns the meaning of words. 

But what if, instead of studying sentence by sentence, you could look at the *entire English language all at once*? 

That’s the idea behind **GloVe** (which stands for **Glo**bal **Ve**ctors). Developed by researchers at Stanford, GloVe is Word2Vec's biggest rival. Instead of playing guessing games, GloVe uses the power of a giant spreadsheet!

---

## The Co-Occurrence Matrix (The Giant Spreadsheet)

Imagine you want to know how similar the words "Ice" and "Steam" are. 

GloVe starts by reading millions of books and creating a massive grid—a spreadsheet called a **Co-occurrence Matrix**. 

- It puts every single word in the dictionary as a row.
- It puts every single word as a column.
- Whenever two words show up in the same sentence, it adds a +1 in the box where they intersect.

Let's say it counts how often "Ice" and "Steam" show up in sentences with other words like "Solid", "Gas", and "Water".

By looking at this giant spreadsheet, GloVe instantly sees the big picture: Ice and Steam are related to Water, but are opposites when it comes to being Solid or Gas.

## The Problem: The Spreadsheet is Too Big!

Here’s the catch: If your dictionary has 100,000 words, this spreadsheet will have **10 billion boxes** ($100,000 \times 100,000$). That takes up way too much computer memory, and most of the boxes will be empty (a zero) because most words never appear next to each other (like "platypus" and "skyscraper").

## Matrix Factorization: Shrinking the Spreadsheet

To fix this, GloVe uses a math trick called **Matrix Factorization**. 

Think of Matrix Factorization like zipping a giant file on your computer. It takes that massive, mostly empty spreadsheet and *squishes* it down into two smaller, much denser grids. 

Instead of needing 100,000 numbers to describe a word, the math squishes it down so each word is described by just 100 or 300 numbers (our vectors!).

## GloVe vs Word2Vec

So, which one is better?

- **Word2Vec** learns by zooming in on small, local sentences (predicting words). It’s great at understanding complex analogies (like King - Man + Woman = Queen).
- **GloVe** learns by zooming out and looking at the global stats (the giant spreadsheet). It’s great at understanding how words relate to each other overall.

In the real world, both are awesome and are often used to do the same job: giving our AI the "meaning coordinates" it needs to understand text!

## Python Code Example

Here is how to build a co-occurrence matrix ("the spreadsheet"), factorize it into dense word embeddings using Singular Value Decomposition (SVD), and formulate GloVe's weighted loss objective in PyTorch:

```python r
import torch

# 1. Small corpus and vocabulary
corpus = [
    ["ice", "is", "solid", "water"],
    ["steam", "is", "gas", "water"],
    ["ice", "and", "steam", "are", "water"],
]
vocab = ["ice", "steam", "solid", "gas", "water"]
word2idx = {w: i for i, w in enumerate(vocab)}

# 2. Build the Co-occurrence Matrix (The "Giant Spreadsheet")
window_size = 2
co_matrix = torch.zeros((len(vocab), len(vocab)))

for sentence in corpus:
    for i, target in enumerate(sentence):
        if target not in word2idx:
            continue
        start = max(0, i - window_size)
        end = min(len(sentence), i + window_size + 1)
        for j in range(start, end):
            if i != j and sentence[j] in word2idx:
                co_matrix[word2idx[target], word2idx[sentence[j]]] += 1.0

print("Co-occurrence Matrix:")
print(co_matrix)

# 3. Matrix Factorization via SVD (Squishing into dense vectors)
# Decompose matrix into U, S, Vh. Truncating to 2 dimensions:
U, S, Vh = torch.linalg.svd(co_matrix)
embedding_dim = 2
dense_embeddings = U[:, :embedding_dim] * torch.sqrt(S[:embedding_dim])

print("\nDense Word Embeddings (2D):")
for word, idx in word2idx.items():
    coords = [round(val, 3) for val in dense_embeddings[idx].tolist()]
    print(f"{word:6s} -> {coords}")

# 4. GloVe Weighting & Loss Formulation
def glove_loss(w_i, w_j, b_i, b_j, X_ij, x_max=100.0, alpha=0.75):
    """
    GloVe loss: weights co-occurrences so frequent words don't overpower rare ones.
    """
    # Weighting function f(X_ij) = (X_ij / x_max)^alpha if X_ij < x_max else 1
    weights = torch.where(X_ij < x_max, (X_ij / x_max) ** alpha, torch.ones_like(X_ij))
    
    # GloVe objective: w_i^T * w_j + b_i + b_j ≈ log(X_ij)
    prediction = (w_i * w_j).sum(dim=-1) + b_i + b_j
    loss = weights * ((prediction - torch.log(X_ij)) ** 2)
    return loss.sum()

# Extract non-zero co-occurrences
mask = co_matrix > 0
i_indices, j_indices = torch.where(mask)
X_values = co_matrix[mask]

# Compute loss with initialized embeddings and zero biases
w_i = dense_embeddings[i_indices]
w_j = dense_embeddings[j_indices]
b_i = torch.zeros(len(X_values))
b_j = torch.zeros(len(X_values))

loss = glove_loss(w_i, w_j, b_i, b_j, X_values)
print(f"\nGloVe Loss on Embeddings: {loss.item():.4f}")
```
