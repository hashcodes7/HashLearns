# Luong Attention: The Puzzle Pieces

Bahdanau's "Flashlight" (Additive Attention) proved that letting the Decoder look back at the original sentence completely fixed the Seq2Seq bottleneck. The AI could finally translate long paragraphs flawlessly!

But there was a catch. Bahdanau used a mini neural network to calculate the flashlight scores. If you are translating a 100-word paragraph, the AI has to run that mini neural network 100 times *for every single translated word*. It was painfully slow.

A year later, a researcher named Minh-Thang Luong found a math cheat code that made Attention lightning fast. This is known as **Multiplicative Attention** (or Dot-Product Attention).

---

## The Puzzle Piece Analogy

Instead of building a separate mini-brain to judge the words, Luong realized that neural network vectors (the lists of numbers representing words) naturally act like puzzle pieces. 

In linear algebra, if you have two vectors and you want to know how similar they are, you don't need a neural network. You just **multiply them together** (using a Dot Product).

- If the vectors are pointing in the exact same direction (they mean the same thing), multiplying them gives a **huge positive number**. They fit together perfectly!
- If they are completely unrelated, multiplying them gives a number near **zero**.

<div style={{backgroundColor: '#e6f7ff', padding: '10px', borderRadius: '5px'}}>
<strong>The Shortcut:</strong> To figure out where to point the flashlight, the Decoder just takes its current thought vector and multiplies it directly against every English word vector! 
</div>

### Why is this better?

Because computers (specifically GPUs) are insanely good at multiplication. 

While Bahdanau's method required feeding data through a complex neural network one by one, Luong's method allows the GPU to multiply all 100 words in a single, massive math operation that takes a fraction of a millisecond. 

## The Core Difference

- **Bahdanau (Additive):** "Let's build a tiny robot to look at the words and tell us which one is important." (Flexible, but slow).
- **Luong (Multiplicative):** "Let's just smash the vectors together with multiplication and see which ones naturally stick!" (Slightly less flexible, but blindingly fast).

Because it was so fast, Luong's Dot-Product math became the absolute foundation for the future of AI. In fact, this exact multiplication trick is what powers the modern Transformers inside ChatGPT today!

## Python Code Example

Here is how simple Luong (Dot-Product) Attention is in PyTorch—just a single batch matrix multiplication (`torch.bmm`) replaces Bahdanau's entire mini neural network:

```python r
import torch
import torch.nn as nn
import torch.nn.functional as F

class LuongAttention(nn.Module):
    """
    Luong (Multiplicative) Attention Layer.
    Supports 'dot' and 'general' scoring:
      - dot:     score(h_t, h_s) = h_t^T * h_s
      - general: score(h_t, h_s) = h_t^T * W * h_s
    """
    def __init__(self, hidden_dim, method="dot"):
        super().__init__()
        self.method = method
        self.hidden_dim = hidden_dim
        
        if self.method == "general":
            self.linear = nn.Linear(hidden_dim, hidden_dim, bias=False)
        elif self.method != "dot":
            raise ValueError("Method must be 'dot' or 'general'")

    def forward(self, decoder_hidden, encoder_outputs):
        # decoder_hidden:  [batch_size, hidden_dim]
        # encoder_outputs: [batch_size, seq_len, hidden_dim]
        
        if self.method == "dot":
            # Fast dot product between decoder query and all encoder words:
            # [batch, seq_len, hidden] x [batch, hidden, 1] -> [batch, seq_len]
            scores = torch.bmm(encoder_outputs, decoder_hidden.unsqueeze(2)).squeeze(2)
        elif self.method == "general":
            # Multiplicative scoring with learnable matrix W
            projected = self.linear(decoder_hidden).unsqueeze(2)
            scores = torch.bmm(encoder_outputs, projected).squeeze(2)

        # Softmax turns raw dot products into percentage weights (sum to 1)
        attention_weights = F.softmax(scores, dim=-1)

        # Context vector: weighted sum of encoder hidden states
        # [batch, 1, seq_len] x [batch, seq_len, hidden] -> [batch, hidden]
        context = torch.bmm(attention_weights.unsqueeze(1), encoder_outputs).squeeze(1)

        return context, attention_weights


# --- Example Usage ---
if __name__ == "__main__":
    torch.manual_seed(42)

    batch_size = 1
    seq_len = 4       # e.g., ["The", "black", "cat", "slept"]
    hidden_dim = 3    # Representation vector size
    
    # Encoder representations for each word
    encoder_outputs = torch.randn(batch_size, seq_len, hidden_dim)
    
    # Decoder state representing current word to translate
    decoder_hidden = torch.randn(batch_size, hidden_dim)

    # Compute Luong dot-product attention
    attention = LuongAttention(hidden_dim=hidden_dim, method="dot")
    context, weights = attention(decoder_hidden, encoder_outputs)

    words = ["The", "black", "cat", "slept"]
    print("Attention Weights (how much flashlight each word gets):")
    for word, weight in zip(words, weights[0].tolist()):
        print(f"  {word:6s} -> {weight:.4f} ({weight * 100:.1f}%)")

    print("\nResulting Context Vector shape:", context.shape)
    print("Context Vector:", context.squeeze(0).tolist())
```
