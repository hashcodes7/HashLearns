# PyTorch Implementation: LEGO Bricks

We've spent a lot of time talking about the intense math behind LSTMs and GRUs—VIP Highways, Sigmoid valves, Update gates, and Bidirectional reading. 

You might be terrified that you have to write all of this math by hand. 

Don't panic! The beauty of modern AI frameworks like **PyTorch** is that they package all of this complex math into simple, pre-built LEGO bricks. You don't need to know how to build the engine; you just need to know how to start the car.

---

## 1. Summoning an LSTM

To create an LSTM in PyTorch, you only need one single line of code!

```python
import torch
import torch.nn as nn

# Create an LSTM network!
# input_size: The size of your word vectors (e.g., 300 coordinates from Word2Vec)
# hidden_size: How big you want the AI's "memory clipboard" to be (e.g., 128)
my_lstm = nn.LSTM(input_size=300, hidden_size=128)
```

That's it! PyTorch automatically handles all the Forget, Input, and Output gates behind the scenes. 

## 2. Passing Data Through

When you want to pass a sentence (a sequence of word vectors) into your LSTM, it will return two things:
1. **The Outputs:** The short-term memory for *every single word* in the sentence.
2. **The Final States:** The very last VIP Highway (Cell State) and short-term memory (Hidden State) at the end of the sentence.

```python
# Pass your sentence into the LSTM
# Remember, PyTorch expects a tensor (a grid of numbers)
outputs, (final_hidden, final_cell) = my_lstm(my_sentence_tensor)
```

## 3. Switching to a GRU

What if you decide the LSTM is running too slowly, and you want to try the "2-in-1 Shampoo" GRU instead? 

You literally just change four letters in your code. 

```python
# Create a GRU instead!
my_gru = nn.GRU(input_size=300, hidden_size=128)

# Pass the data through (Notice there is no final_cell, because GRUs don't have a VIP highway!)
outputs, final_hidden = my_gru(my_sentence_tensor)
```

## 4. Making it Bidirectional

Do you want your AI to read the sentence both forwards and backwards so it understands context perfectly? 

Just set `bidirectional=True`. 

```python
# Create a Bidirectional LSTM!
my_bilstm = nn.LSTM(input_size=300, hidden_size=128, bidirectional=True)
```

PyTorch automatically clones the network, runs one forward, runs one backward, and glues the outputs together for you. It feels almost like cheating!

---

## Python Code Example

Here is a complete, runnable example putting all three models together—LSTM, GRU, and Bidirectional LSTM—with dummy sequential data showing how the tensor dimensions work:

```python r
import torch
import torch.nn as nn

# Set seed for reproducible results
torch.manual_seed(42)

# Dimensions: batch of 2 sentences, 5 tokens each, 300-dim word vectors
seq_len = 5
batch_size = 2
input_size = 300
hidden_size = 128

# Input tensor shape: (seq_len, batch_size, input_size)
sentence_tensor = torch.randn(seq_len, batch_size, input_size)

# --- 1. Standard LSTM ---
lstm = nn.LSTM(input_size=input_size, hidden_size=hidden_size)
lstm_out, (lstm_h, lstm_c) = lstm(sentence_tensor)
print("=== LSTM ===")
print("Output shape:     ", lstm_out.shape)  # [5, 2, 128]
print("Final Hidden shape:", lstm_h.shape)   # [1, 2, 128]
print("Final Cell shape:  ", lstm_c.shape)   # [1, 2, 128]

# --- 2. Standard GRU ---
gru = nn.GRU(input_size=input_size, hidden_size=hidden_size)
gru_out, gru_h = gru(sentence_tensor)
print("\n=== GRU ===")
print("Output shape:     ", gru_out.shape)   # [5, 2, 128]
print("Final Hidden shape:", gru_h.shape)     # [1, 2, 128]

# --- 3. Bidirectional LSTM ---
bilstm = nn.LSTM(input_size=input_size, hidden_size=hidden_size, bidirectional=True)
bilstm_out, (bilstm_h, bilstm_c) = bilstm(sentence_tensor)
print("\n=== Bidirectional LSTM ===")
print("Output shape:     ", bilstm_out.shape) # [5, 2, 256] -> hidden_size * 2
print("Final Hidden shape:", bilstm_h.shape)  # [2, 2, 128] -> num_directions = 2
```
