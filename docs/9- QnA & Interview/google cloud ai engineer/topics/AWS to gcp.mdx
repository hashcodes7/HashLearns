| AWS service | GCP equivalent                              | What it does                                                                                                                            |
| ----------- | ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| EC2         | Compute Engine                              | Virtual machines to run applications, servers, and workloads.                                                                           |
| S3          | Cloud Storage                               | Object storage for files, images, datasets, backups, and documents.                                                                     |
| ECS         | Google Kubernetes Engine (GKE) or Cloud Run | Runs containerized applications. GKE manages Kubernetes; Cloud Run is simpler for deploying containers.                                 |
| IoT Core    | No direct equivalent                        | Google Cloud IoT Core was retired in 2023. Common replacements use partner IoT platforms or MQTT brokers integrated with Pub/Sub.       |
| Bedrock     | Vertex AI                                   | Builds generative AI applications using foundation models, model APIs, and related AI tooling.                                          |
| CloudWatch  | Cloud Monitoring + Cloud Logging            | Collects metrics, logs, dashboards, alerts, and operational diagnostics.                                                                |
| Lambda      | Cloud Functions                             | Runs event-driven functions without managing servers. Cloud Run functions is the current terminology used for the functions experience. |
