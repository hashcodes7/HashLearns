## 1. 2025–2026 Interview Trends & Format Changes

:::info Key Algorithmic Trends
- **Graphs Dominance**: Graph algorithms appear in **76% of onsite loops** at L4+.
- **Top-Tier Patterns**: Sliding window and binary search on answer space are top-tier recurring patterns.
- **Rising Topics**: Trie and Union-Find (Disjoint Set Union) questions are steadily rising.
- **Difficulty Distribution**: Approximately **19%** of reported onsite problems are LeetCode Hard. Follow-up extensions are standard across all interviews.
- **Google Distinctive Topics**: Segment Tree and Fenwick Tree (Binary Indexed Tree / BIT) problems remain a Google-distinctive category rarely seen at other FAANG companies.
:::

:::tip 2026 Interview Process Evolution
- **AI-Assisted "Code Comprehension" Round (Piloting in 2026)**:
  - Candidates read, debug, and optimize an existing codebase with **Gemini available** in a CoderPad-style environment (file explorer + code editor + AI chat).
  - Interviewers explicitly evaluate and score **AI fluency**: prompt engineering quality, output validation, and debugging/refactoring AI-generated code.
  - Piloted in H2 2026 for junior/mid-level roles on select US teams, expanding to L5 loops (*reported August 2026: candidates explain what unfamiliar Gemini-generated code does, isolate bugs, and propose architectural refactors*).
  - *Context*: Over 75% of new internal Google code is AI-assisted.
- **In-Person Rounds Reinstated**:
  - Reinstated for technical hires to combat AI-assisted screening fraud.
  - Hybrid loop structure reported for L4: 2 virtual rounds $\to$ rapid recruiter feedback $\to$ 2 in-person rounds.
- **Google Hiring Assessment (GHA)**:
  - Mandatory online assessment prior to the technical phone screen.
- **Technical Deep-Dive in Googleyness & Leadership (G&L)**:
  - Now includes a part-technical architecture defense: candidates defend the technical decisions and trade-offs of a real production system they built under rigorous interviewer scrutiny.
- **Early-Career Format Shift (L3/L4)**:
  - One traditional coding round is replaced by an open-ended engineering problem session focusing on approach, trade-offs, and ambiguous problem derivation over a single rigid answer.
  - Strict production-ready code grading at L4. No dedicated System Design round below L5.
  - Screens often open with a 10-minute resume architecture deep-dive (e.g., Kafka, Redis, API gateways, streaming systems) prior to coding.
:::
