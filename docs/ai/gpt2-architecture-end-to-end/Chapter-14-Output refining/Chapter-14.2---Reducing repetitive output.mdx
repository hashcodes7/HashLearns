This is because we are generating without randomness. always the top answer is being picked
we do this by introducing randomness in our generation
so change the generation call from 

``` python
from g_text_generator import generate_text
import tiktoken
tokenizer = tiktoken.get_encoding("gpt2")
generated_text = generate_text(
    model=model,
    tokenizer=tokenizer,
    prompt="Tell me about AI",
    device=device,
    max_new_tokens=256,
)
print(generated_text)
```

to 
``` python
from g_text_generator import stream_text
import tiktoken
tokenizer = tiktoken.get_encoding("gpt2")
# We use the for loop to iterate over the generator and print live
for text_chunk in stream_text(
    model=model,
    tokenizer=tokenizer,
    prompt="Tell me about AI",
    device=device,
    max_new_tokens=256,
    temperature=0.7,   # Added temperature to fix repetition
    top_k=40           # Added top_k to fix repetition
):
    print(text_chunk, end="", flush=True)
print()
```

we introduced 2 things
- top_k=40 
- temperature=0.7, 
These will introduce some randomness and make our answer not be repeatitive
