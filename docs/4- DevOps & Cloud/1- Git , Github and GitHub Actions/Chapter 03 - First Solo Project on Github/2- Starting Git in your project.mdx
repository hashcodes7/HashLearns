GIT is started in your project via these commands

- Start Git Local Repository in the project folder
```
git init
```

- Configure your git's username and email (optional if you dont want to use global (*for your entire pc*) git username)
``` bash
git config user.name "Your Name"
git config user.email "you@example.com"
```

<span style="color:#2f9e44">Thats it. a local git repo with your current git has been started in your project</span>
Now if you want to put this git online on remote repo on github, See next chapter about how to create a repo there.
