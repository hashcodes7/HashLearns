## Downloading Git
- you can download git from here [Link](https://git-scm.com/install/windows)
- Github Registration Link is here [Link](https://github.com)

## Log in to Git (this doesnt mean we are logging in github)

- we want to specify git who are we, so we have to log in to git. if the <span style="color:#2f9e44">PC is yours</span> and you will manage every project you can set a <span style="color:#2f9e44">Global Username and email</span>
``` bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

- if<span style="color:#1c7ed6"> PC is not yours</span> but you just want project specific login of git in that pc, <span style="color:#1c7ed6">dont set git for global</span>, use these project specific git login commands instead
``` bash
git config user.name "Your Name"
git config user.email "you@example.com"
```

That concludes 1 time setup of Git and Github account creation for you. you will see this page again rarely if ever.
