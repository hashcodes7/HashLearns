# Adding Comics: A Step-by-Step Guide

The **`ComicCarousel`** component (`hashcomics😋`) is **globally registered** across the entire HashLearns site. You can use `<ComicCarousel />` anywhere in any `.md` or `.mdx` file **without writing any `import` statements at all**!

---

## ⚡ The Minimal Working Syntax

To render comics with optional descriptions, pass `folder={require.context('./assets')}` (which tells Webpack to bundle all local images in `./assets`) along with clean `['filename', 'description']` pairs:

```mdx
# Downloading Git & Installing it

<ComicCarousel 
  folder={require.context('./assets')}
  images={[
    ['img1.png', "click on the download button"],
    ['img2.png', "click on the install button"]
  ]}
/>
```

---

## 🔍 Why `folder={require.context('./assets')}` is Required:

1. **Webpack Image Bundling**: Webpack is a static site bundler. It needs `folder={require.context('./assets')}` so it can find, process, and copy your local `.png` screenshot files from disk into the website build assets folder.
2. **Correct Filename**: Ensure the filename in your array (e.g. `img1.png` or `git1.png`) matches the exact filename inside your local `./assets/` folder.

### 🌟 Features Included:
- **`Prev <` & `Next >` Controls**: Easy navigation through panels.
- **Center Description**: Clean white text centered between buttons (supports up to 2 lines!).
- **Lightbox Zoom**: Click any image panel to open a full-screen zoom overlay.
- **`1 / 3` Pill Counter**: Real-time panel counter.
- **`hashcomics😋` Signature**: Minimalist brand tag in top-left corner.
- **Keyboard Support**: Navigate using `←` and `→` arrow keys on your keyboard.
