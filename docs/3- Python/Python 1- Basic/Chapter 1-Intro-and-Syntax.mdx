### Indentation
Indentation is the spaces at the beginning of a code line.
This tells the code that a particular line is enclosed within the parent code line.
eg 

```python
if 5 > 2:
print("Five is greater than two!")
```
means that if 5>2 do nothing

```python
if 5 > 2:
  print("Five is greater than two!")
```
but this one tells that if 5>2 then run the print statement or any statement that is under current line.
