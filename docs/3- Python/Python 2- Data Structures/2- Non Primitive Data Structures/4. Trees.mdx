# Binary Trees & Search Trees

> A Tree is a hierarchical non-primitive data structure composed of nodes connected by edges, starting from a single Root node.

## Interactive BST Search & Traversal

``` python r 
class node:
    def _init_(self,data):
        self.data = data
        self.left = None
        self.right = None

def insert(root,data):
    if root is None:
        return node(data)
    if data < root.data:
        root.left = insert(root.left,data)
    else:
        root.right = insert(root.right,data)
    return root

def search(root,data):
    if root is None or root.data == data:
        return root
    if data < root.data:
        return search(root.left,data)
    else:
        return search(root.right,data)
```
